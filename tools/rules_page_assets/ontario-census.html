全書掃描決定了什麼What the census decided

  • 新增AddedUNTIL58 句指示的義務「持續到…為止」，其中 37 句 v0 寫不出來。58 instructions end a duty “until …”; v0 could not write 37 of them.
  • 新增AddedSTRENGTH FROM239 句（12%）法律效力不明；記下效力來源，之後才能有根據地調整。239 sentences (12%) have unclear legal strength; recording its source lets it be raised later, with a reason.
  • 新增AddedSEE245 張圖；圖跟著規則走，但不改變規則何時適用，所以是附註而不是子句。245 figures; a figure goes with a rule but never changes when it applies, so it is metadata, not a clause.
  • 保留KeptWHEN WHILE ONLY IF UNLESS …全部都有用到：WHEN 1,070、WHILE 153、ONLY IF 96、UNLESS 46、EXCEPTION TO 74、IF VIOLATED 202。All in use: WHEN 1,070, WHILE 153, ONLY IF 96, UNLESS 46, EXCEPTION TO 74, IF VIOLATED 202.
  • 保留KeptSHOULD祈使句仍算建議：最常見的指示（1,185 句，59%）；段落或違規表仍可讓它成為法規。Bare imperatives stay advice: the most common instruction (1,185, 59%); section context or an offence table can still make one law.
  • 保留KeptSHOULD WATCH FOR全部 153 句提醒都寫得出來，不需另設關鍵字。All 153 cautions fit it; no separate keyword.
  • 不新增Not addedBEFORE / AFTER209 句提到先後，174 句用步驟順序、WHEN about to … 或 ONLY IF … 就寫得出；只有 10 句需要關鍵字。174 of 209 order mentions fit with step order, WHEN about to … or ONLY IF …; 10 asked for a keyword.
  • 不新增Not addedIF … THEN45 條「如果…就」規則中 37 條用 WHEN 就寫得出，所以 IF … THEN 只用在程序分支。37 of 45 “if … then” rules fit with WHEN, so IF … THEN stays a procedure branch.
  • 不新增Not addedSO THAT257 句目的中 248 句用 BECAUSE this … 或 “to …” 就寫得出。248 of 257 purposes fit with BECAUSE this … or “to …”.
  • 不新增Not added數量 · 清單 · 路權numbers · lists · right of way數量、清單、路權屬於用詞：203 句數字用固定片語，清單每項各一條，“yield the right-of-way to” 是動詞片語。Numbers, lists and right of way are wording: fixed phrases for 203 numbers, one statement per list item, “yield the right-of-way to” as a verb phrase.
